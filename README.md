⚡ ZrazTrack (ZRAZNE)fur da Zraz — Real-time group fitness & habit synchronization web app built for Luke, Ross, and Elliot.🚀 OverviewZrazTrack is a mobile-first, high-energy progressive web app (PWA) designed to keep group fitness goals and daily workout habits in sync. Styled with a dark neon cyberpunk aesthetic, it gives every member of the squad real-time visibility into each other's progress, habit streaks, weight goals, and weekly workout plans.🔥 Key Features👥 Multi-User Group Sync: Seamlessly switch perspectives between Luke, Ross, and Elliot, or share custom view links (?user=luke, ?user=ross, ?user=elliot).⚡ Quick Progress Logging: Log workout minutes with quick preset buttons (+2m, +15m, +30m, +60m), custom goal values, and session notes.🏋️ Weekly Workout Routines: Built-in daily schedule tracking (e.g., Kettlebell Push/Pull/Legs, Zone 2 Runs, hanging routines).🔥 Live Feed & Social Reactions: Broadcast live workout achievements to the group and send quick motivational boosts (🔥, 👏, 💪).☁️ Realtime Cloud Sync: Powered by Firebase Firestore with automatic offline fallback to localStorage.📱 Native Mobile Feel (PWA): Standalone app mode support for iOS Safari and Android Chrome home screens.🎯 Goal Lifecycle Management: Track active habits, target weight endpoints, and archived achievements.🛠 Tech StackFrontend: HTML5, JS (ES Modules), Tailwind CSSDesign & Icons: Google Fonts (Orbitron & Inter), Phosphor IconsBackend & Database: Firebase Firestore (v11) & Anonymous AuthenticationDeployment: GitHub Pages / Single Static HTML File📦 Deployment & SetupOption 1: Live Deployment via GitHub PagesIn your GitHub repository (CooperRiver2/ZrazTrack), go to Settings -> Pages.Under Build and deployment -> Branch, select main branch and / (root) folder.Click Save.
